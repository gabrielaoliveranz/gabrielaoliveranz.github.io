That taught me to question numbers before trusting them, understand how processes create data, and recognise when something looks technically correct but operationally wrong. Now I combine that judgement with SQL, Python, Power BI and modern data workflows.

Data quality

I don't trust a number because a dashboard says it.

I trust it after I've asked where it came from, how it was transformed, what assumptions were made, and whether the result behaves the way reality says it should.
